# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any ZRM repository, please report it responsibly.

**Email:** [security@zrm.dk](mailto:security@zrm.dk)

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected repository and version/branch
- Potential impact

## Response Timeline

| Stage | Timeframe |
|-------|-----------|
| Acknowledgement | Within 48 hours |
| Status update | Within 7 days |
| Fix or mitigation | As soon as reasonably possible |

## Disclosure

We follow coordinated disclosure. Please do not publicly disclose the vulnerability until we have had a chance to address it and notify affected users.

## Scope

This policy applies to all repositories in the [ZRM-ApS](https://github.com/ZRM-ApS) organization.
